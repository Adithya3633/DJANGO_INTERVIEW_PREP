# MODULE 7 – API Integration and CRUD Operations
## 86. What is API integration in React?
Connecting a React frontend to a backend service to send or receive data, using the Fetch API or Axios. In your CRM project:
```
React Frontend
   | HTTP Request
   v
Django REST API
   v
Database
   v
JSON Response
   v
React UI Update
```
## 87. What is Fetch API?
A built-in JavaScript function used to make HTTP requests.
```js
fetch("https://jsonplaceholder.typicode.com/users")
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.log(error));
```
## 88. What is Axios?
A JavaScript HTTP client library used to make API requests.
```js
import axios from "axios";

axios.get("https://jsonplaceholder.typicode.com/users")
  .then(response => console.log(response.data))
  .catch(error => console.log(error));
```
## 89. Difference between Fetch and Axios?
| Fetch | Axios |
| Built into modern browsers | External library |
| Needs explicit JSON parsing | Automatically parses JSON responses |
| HTTP errors need manual status checking | Rejects non-2xx responses by default |
| Supports request configuration | Supports interceptors and convenient configuration |
## 90. What is async/await?
JavaScript syntax for working with Promises in a more readable way.
```js
async function getUsers() {
  try {
    const response = await fetch("https://jsonplaceholder.typicode.com/users");
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.log(error);
  }
}
```
## 91. What is a Promise?
An object representing the eventual completion or failure of an asynchronous operation. Three states:
- Pending
- Fulfilled
- Rejected
```js
fetch("/api/users")
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.log(error));
```
## 92. How do you fetch API data when a component loads?
Use useEffect with useState. Complete interview-ready code:
```jsx
function App() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState("");

  useEffect(() => {
    async function getUsers() {
      try {
        const response = await fetch("https://jsonplaceholder.typicode.com/users");
        if (!response.ok) {
          throw new Error("Failed to fetch users");
        }
        const data = await response.json();
        setUsers(data);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    }
    getUsers();
  }, []);

  if (loading) return <h2>Loading...</h2>;
  if (error) return <h2>{error}</h2>;

  return (
    <div>
      <h1>User List</h1>
      {users.map(user => <p key={user.id}>{user.name}</p>)}
    </div>
  );
}
```
Explain the flow:
- useState stores users, loading and error.
- useEffect runs after initial mounting.
- Fetch sends a GET request.
- response.json() converts the JSON response into JavaScript data.
- setUsers() updates the state.
- React re-renders and displays users.
- finally updates the loading status.
## 93. What is CRUD?
| Operation | HTTP Method | Purpose |
| Create | POST | Add data |
| Read | GET | Retrieve data |
| Update | PUT/PATCH | Modify data |
| Delete | DELETE | Remove data |
## 94. How do you perform a GET request?
GET retrieves information from the backend.
```jsx
useEffect(() => {
  fetch("https://api.example.com/users")
    .then(res => res.json())
    .then(data => setUsers(data));
}, []);
```
## 95. How do you perform a POST request?
```jsx
async function addUser() {
  const response = await fetch("https://api.example.com/users", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ name: "Adithya", email: "adithya@example.com" })
  });
  const data = await response.json();
  console.log(data);
}
```
- POST sends data to the server.
- JSON.stringify() converts a JavaScript object into a JSON string.
- Content-Type tells the server the request body format.
## 96. How do you perform a PUT request?
PUT is generally used to replace a resource representation.
```jsx
async function updateUser(id) {
  const response = await fetch(`https://api.example.com/users/${id}`, {
    method: "PUT",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ name: "Updated Name", email: "updated@example.com" })
  });
  const data = await response.json();
  console.log(data);
}
```
## 97. What is the difference between PUT and PATCH?
- PUT generally replaces the complete resource representation.
- PATCH updates selected fields of a resource.
```js
// PUT body
{ "name": "Adithya", "email": "adithya@example.com" }

// PATCH body
{ "name": "Updated Name" }
```
## 98. How do you perform DELETE in React?
```jsx
async function deleteUser(id) {
  const response = await fetch(`https://api.example.com/users/${id}`, {
    method: "DELETE"
  });
  if (response.ok) {
    setUsers(prev => prev.filter(user => user.id !== id));
  }
}
```
The filter() method creates a new array excluding the deleted user.
## 99. What is JSON?
JavaScript Object Notation: a lightweight data-interchange format commonly used for communication between frontend and backend.
```json
{
  "name": "Adithya",
  "role": "React Developer",
  "skills": ["HTML", "CSS", "JavaScript", "React"]
}
```
## 100. What is the difference between JSON.stringify() and JSON.parse()?
```js
// stringify: JavaScript object -> JSON string
const jsonData = JSON.stringify({ name: "Adithya" });

// parse: JSON string -> JavaScript object
const user = JSON.parse('{"name":"Adithya"}');
```
## 101. What is response.json()?
A Fetch API method that reads the response body and parses JSON into a JavaScript value. It returns a Promise. It is not the same as calling JSON.parse() directly on a response object.
## 102. What is CORS?
Cross-Origin Resource Sharing: a browser security mechanism that controls whether a web page from one origin can access resources from another origin.
- React: http://localhost:5173
- Django: http://localhost:8000
These are different origins because the ports differ. The backend must return appropriate CORS headers to allow the frontend origin.
## 103. What is the difference between frontend and backend?
| Frontend | Backend |
| User-facing interface | Server-side logic |
| React | Django |
| HTML, CSS, JS | Python |
| Displays information | Processes information |
| Sends API requests | Handles API requests |
| Updates UI | Interacts with database |
## 104. How do you handle API errors?
Use try/catch, check the HTTP response status and display an appropriate message.
```jsx
async function getData() {
  try {
    const response = await fetch("/api/users");
    if (!response.ok) {
      throw new Error("API request failed");
    }
    const data = await response.json();
    setUsers(data);
  } catch (error) {
    setError(error.message);
  }
}
```
Remember: fetch does not automatically throw for HTTP responses such as 404 or 500. You need to check response.ok.
## 105. What is loading state in React?
State that indicates whether an asynchronous operation is currently running.
```jsx
const [loading, setLoading] = useState(false);

async function fetchData() {
  setLoading(true);
  try {
    const response = await fetch("/api/users");
    setUsers(await response.json());
  } finally {
    setLoading(false);
  }
}
```
## 106. What is optimistic UI updating?
Updating the UI immediately, before receiving confirmation from the server. If the request fails, roll back the change or show an error. Example: immediately removing a task from the list when the user clicks Delete while the backend request is still processing.
## 107. How do you avoid unnecessary API calls?
- Use appropriate Effect dependencies
- Avoid fetching inside the component body
- Debounce search requests
- Cache responses when appropriate
- Cancel obsolete requests
- Use libraries such as TanStack Query when suitable
## 108. What is debouncing?
Delays execution of a function until a specified period has passed without another call. Example use case: search suggestions.
```jsx
useEffect(() => {
  const timer = setTimeout(() => {
    if (search.trim()) {
      fetchUsers(search);
    }
  }, 500);

  return () => clearTimeout(timer);
}, [search]);
```
If the user types again within 500 ms, the previous timer is cleared.
## 109. What is throttling?
Ensures a function executes at most once within a specified time interval. Example use cases: scroll events, window resizing, repeated button actions.
- Debouncing waits until activity stops.
- Throttling limits how frequently a function executes.
